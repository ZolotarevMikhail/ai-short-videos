# ИИ-видео: короткий ролик по текстовому описанию

Пример работы: ролик, полностью сгенерированный нейросетью по текстовому промпту.

## Работа

| Файл | Что в нём | Модель |
|---|---|---|
| `videos/biker-sunset.mp4` | Мотоциклист на Harley-Davidson едет по пустынной дороге в закат (5 сек, 1280×720) | PixVerse V6 (сгенерировано в PixVerse — фирменная метка в углу) |

Промпт — в `промпты.md`.

## Как посмотреть

По ссылке витрины ролик встроен прямо на страницу:
`https://zolotarevmikhail.github.io/ai-portfolio-showcase/` (проект 2).

## Полный кейс «от сценария до готового ролика»

Пример второго уровня — семейный ролик «Море зовёт!» (20 сек с музыкой и
титрами) и весь его процесс описаны отдельно: репозиторий `ai-video-pipeline`.

## Технологии

- Генерация видео по текстовым промптам (PixVerse);
- Оценка результатов нескольких генераторов и выбор лучшей версии.

## Лицензия

Ролик сделан автором репозитория по собственному промпту.
