# ИИ-видео: короткие ролики по текстовому описанию

Два примера коротких роликов, полностью сгенерированных нейросетями по текстовому промпту.

## Работы

| Файл | Что в нём | Модель |
|---|---|---|
| `videos/biker-sunset.mp4` | Мотоциклист на Harley-Davidson едет по пустынной дороге в закат (5 сек, 1280×720) | PixVerse V6 (сгенерировано в PixVerse — фирменная метка в углу) |
| `videos/family-sea.mp4` | Семья крошечных человечков: сборы, дорога, море — с музыкой и титрами (20 сек, 480×854, 9:16) | Wan 3.0 через API + наложение титров |

Промпты — в `промпты.md`.

## Как посмотреть

Файлы mp4 — нажмите на файл в списке выше и затем View raw, или откройте
витрину-страницу (смотрите репозиторий `ai-portfolio-showcase`), где ролики
встраиваются прямо на страницу.

## Полный кейс «от сценария до готового ролика»

Процесс ДЗ-ролика (сценарий → промпт → генерация → титры) описан отдельно:
`ai-video-pipeline`.

## Технологии

- Генерация видео по текстовым промптам (PixVerse, Wan 3.0);
- Наложение титров и музыка (монтаж).

## Лицензия

Ролики сделаны автором репозитория по собственным промптам.
