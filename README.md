# ИИ-видео: короткие ролики по текстовому описанию

Два примера работ: ролики, полностью сгенерированные нейросетью по текстовым промптам.

## Работы

| Файл | Что в нём | Модель |
|---|---|---|
| `videos/biker-sunset.mp4` | Мотоциклист на Harley-Davidson едет по пустынной дороге в закат (5 сек, 1280×720) | PixVerse V6 (сгенерировано в PixVerse — фирменная метка в углу) |
| `videos/mouse-start-test.mp4` | Скетч: старички канатом подтаскивают компьютерную мышку к экрану с кнопкой START TEST и прыгают на неё, чтобы нажать (5 сек, 1280×720) | PixVerse V6 |

Промпты — в `промпты.md`.

## Полный кейс «от сценария до готового ролика»

Процесс двадцатисекундного ролика «Море зовёт!» (сценарий → промпт →
генерация → титры и музыка) описан отдельно: репозиторий `ai-video-pipeline`.

## Технологии

- Генерация видео по текстовым промптам (PixVerse);
- Сравнение генераторов на одном промпте и выбор лучшей версии.

## Лицензия

Ролики сделаны автором репозитория по собственным промптам.
